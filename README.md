# 🤖 Джарвис — голосовой ассистент для Windows

Голосовой помощник с графическим интерфейсом на Python/Tkinter. Слушает микрофон, распознаёт русскую речь и выполняет команды: открывает программы и сайты, пишет и звонит контактам в Telegram, ищет в Google, закрывает окна — а также умеет собираться в отдельный `.exe`-файл.

## ✨ Возможности

- **Активация по ключевому слову** — по умолчанию «Джарвис», можно сменить на любое своё слово прямо в интерфейсе.
- **Пользовательские команды** («открой ...») — сопоставление голосовой фразы с запуском программы, файла или сайта. Хранятся в `commands.json` и редактируются через GUI (добавление, редактирование, удаление, очистка списка).
- **Контакты и сообщения** («напиши <контакт> <текст>») — находит контакт (с учётом словоформ/алиасов вроде «маме», «маму»), открывает чат в Telegram и подставляет текст. Голосовые названия знаков препинания («запятая», «знак вопроса», «новая строка» и т.д.) автоматически превращаются в символы.
- **Звонки** («позвони <контакт>» / «видеозвони <контакт>») — открывает чат и, если кнопки звонка откалиброваны, кликает по нужной автоматически. Есть отдельный мастер калибровки координат кнопок звонка/видеозвонка/сброса.
- **Автоотправка сообщений** — программное нажатие Enter после открытия чата (через `pyautogui`), с задержкой на прогрузку окна.
- **Поиск в Google** («загугли ...», «найди ...») — открывает браузер с результатами по запросу.
- **Управление окнами** — «закрой» закрывает активное окно стороннего приложения, «закройся»/«выключись» — закрывает сам Джарвис.
- **Озвучивание ответов** через `pyttsx3` (TTS).
- **Нормализация распознавания** — англоязычные бренды («google», «telegram», «youtube» и т.п.), которые Google Speech иногда распознаёт латиницей, автоматически приводятся к кириллице перед сопоставлением с командами.
- **Поддержка High-DPI** — интерфейс не размывается на экранах с масштабом больше 100%.
- Модули распознавания речи, синтеза речи, буфера обмена и автоклика — опциональны: приложение стартует, даже если какой-то из них не установлен, просто соответствующая функция будет недоступна.

## 📦 Структура репозитория

| Файл | Назначение |
|---|---|
| `main.py` | Основной код приложения (GUI + логика голосового ассистента) |
| `translator.py` | Вспомогательный скрипт-переводчик (EN → RU) на базе `deep_translator` |
| `commands.json` | Пользовательские голосовые команды («фраза» → путь к программе/файлу/сайту) |
| `contacts.json` | Контакты для команд «напиши» / «позвони» (платформа, значение, алиасы) |
| `build.bat` | Скрипт автоматической сборки `.exe` через PyInstaller |
| `icon.ico` | Иконка приложения |

## 🛠 Требования

- Windows (часть функций — закрытие активного окна, разворачивание на весь экран, автоклик по звонку — рассчитана именно на Windows; на macOS/Linux приложение запустится, но ряд возможностей будет ограничен).
- Python 3.9+ с модулем **tkinter** (стандартный установщик с [python.org](https://www.python.org/) подходит; версии из Microsoft Store и некоторые сборки Anaconda могут идти без tkinter).
- Рабочий микрофон и интернет-соединение (распознавание речи через Google Speech API).

### Python-зависимости

```
speechrecognition
pyttsx3
pyaudio
pyperclip
pyautogui
```

Установка:

```bash
pip install speechrecognition pyttsx3 pyaudio pyperclip pyautogui
```

> На Windows `pyaudio` иногда не ставится напрямую через pip — в этом случае поставьте готовый wheel-пакет под свою версию Python (например, с сайта unofficial Windows binaries) или используйте `pipwin install pyaudio`.

Для `translator.py` дополнительно нужен:

```bash
pip install deep-translator
```

## 🚀 Запуск из исходников

```bash
git clone <URL-этого-репозитория>
cd <папка-репозитория>
pip install speechrecognition pyttsx3 pyaudio pyperclip pyautogui
python main.py
```

При первом запуске рядом с `main.py` будут созданы/использованы файлы `commands.json`, `contacts.json` и `settings.json` (ключевое слово активации).

## 🏗 Сборка в .exe

В комплекте есть `build.bat`, который под Windows:

1. Проверяет, что у активного Python есть `tkinter`.
2. Ставит `PyInstaller`, если его нет.
3. Ставит недостающие зависимости.
4. Чистит старые `build/`, `dist/`, `*.spec`.
5. Собирает `Джарвис.exe` (`--onefile --windowed`, с иконкой и всеми нужными hidden-imports).

Запуск:

```bat
build.bat
```

Готовый файл появится в `dist\Джарвис.exe`.

## 🗣 Примеры голосовых команд

Ключевое слово в примерах — «Джарвис» (можно сменить в интерфейсе).

| Команда | Что делает |
|---|---|
| «Джарвис, открой браузер» | Запускает приложение/сайт, привязанные к фразе в `commands.json` |
| «Джарвис, напиши маме привет как дела запятая идёшь домой вопросительный знак» | Открывает чат в Telegram и вставляет: «привет как дела, идёшь домой?» |
| «Джарвис, позвони маме» | Открывает чат и (если откалибровано) нажимает кнопку звонка |
| «Джарвис, видеозвони маме» | То же самое, но видеозвонок |
| «Джарвис, сбрось» | Завершает текущий звонок |
| «Джарвис, загугли погода в Киеве» | Открывает браузер с результатами поиска |
| «Джарвис, закрой» | Закрывает активное окно другого приложения |
| «Джарвис, закройся» | Завершает работу самого Джарвиса |

## ⚙️ Настройка команд и контактов

Всё можно делать прямо в интерфейсе приложения (вкладки/панели добавления, редактирования и удаления), либо напрямую редактируя JSON-файлы.

**`commands.json`** — простая пара «голосовая фраза → путь»:

```json
{
    "открой гугл": "C:/Program Files/Google/Chrome/Application/chrome.exe"
}
```

**`contacts.json`** — контакты с платформой, значением и алиасами (словоформами для распознавания):

```json
{
    "маме": {
        "platform": "telegram",
        "value": "username_в_телеграме",
        "aliases": ["маму"]
    }
}
```

## ⚠️ Важные ограничения

- Автоклик по кнопкам звонка работает по **фиксированным координатам экрана**, откалиброванным вручную — если изменить размер/положение окна Telegram, разрешение экрана или обновить сам Telegram, калибровку нужно повторить.
- Автоотправка сообщения (нажатие Enter) сработает не туда, если во время задержки переключить окно или тронуть мышь/клавиатуру.
- Распознавание речи использует Google Speech API — нужно интернет-соединение.
- `translator.py` — вспомогательный, независимый от основного приложения скрипт.
